GMGN

Token metadata, holders, trading activity, and security signals.

Connection setup

Set GMGN_API_KEY in the server environment or use ~/.config/gmgn/.env. An environment value takes priority; an empty value disables the integration. Restart the server after changing its environment.

Reports attribute this source as “Data from GMGN”.

Codex & analysis

Model-assisted explanations through the Pi harness.

Model setup

Set OPENAI_API_KEY and PI_MODEL in the server environment, then restart the server. Select a Codex model to enable Codex. Signing in to the Codex desktop app does not configure this server.

Settings status does not test credentials or model availability. Automatic evidence checks can run without a model.

RPC priority

The endpoints used to read contracts and on-chain activity.

Endpoint setup

Set MYDEVSAID_RPC_<chainId> in the server environment to override a chain's built-in endpoint, then restart the server. For example, MYDEVSAID_RPC_8453 sets the endpoint for Base.

One endpoint is used per chain. Custom endpoints take priority. Built-in endpoints shown as inactive are not automatic failovers.

Read-only settings from your local server. API keys stay hidden; RPCs show hostnames only.
